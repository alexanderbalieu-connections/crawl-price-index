## What the new metrics are

**`policy_layer`** — the denominator ladder (frame 50,000 → parsed 27,975 →
AI-aware 7,091) and per-crawler name recognition: how often each crawler is
*named at all*, and how often it is blocked *once named*. Splits the awareness
gap out of the block rate.

**`archetypes`** — exact 18-cell signatures, 1,882 distinct. Includes the
dominant-template disclosure (1,736 domains sharing one signature = 34.1% of
all explicit blocks) and `ex_template`, every rate recomputed with that cohort
removed.

**`roles`** — training-vs-search asymmetry per domain, role-normalised vendor
rollups with the aggregation rule attached, and within-vendor role
discrimination for the three vendors that field both kinds of crawler.

Existing keys are untouched: a byte-comparison against the live
`dashboard.json` showed zero regressions across all 18 previous keys.
File grows 44 KB → 62 KB.

## Pipeline defects fixed in `sunday-run.command`

1. **The app was never deployed.** The script ran `npx wrangler deploy`
   (marketing site) and stopped. `wrangler pages deploy app` was absent, so
   `app.crawlpriceindex.com` only ever updated when deployed by hand.
2. **`private/domains.json` was never copied into `app/`.** Pages ships only
   what is inside the deployed directory, so the Changes and Domains tabs
   would report "dataset unavailable".
3. **Added:** an automatic gate check after the app deploy — greps the deploy
   output for `Uploading Worker bundle`, then curls `/private/domains.json`
   and `/api/domains` and prints a loud warning if the paid dataset is
   reachable. This is the failure that exposed the dataset for an hour before.

## Editorial rules observed

Five states stay distinct; "declared policy", never "access"; every rate names
its denominator; no ccTLD is called a country; rank is described as sampling
position throughout; the wire sample is untouched; vendor rollups state their
aggregation rule on the view. The within-vendor split table carries an
explicit warning that part of the gap is name recognition rather than
preference — the ratio is framed as an upper bound, not a measurement.
