## 2. A live denominator bug, found while wiring that panel

`rank_bands[].blocked_pct` used the **whole band** as its denominator while
every other rate on the dashboard uses parsed domains. Only 53 of the top 100
domains serve a readable robots.txt, so:

| | GPTBot, rank 1–100 |
|---|---|
| Published | **10.00%** |
| Correct | **18.87%** |

Nearly half. It affected the Segments rank-band chart and the per-crawler

Fixed in `compute-dashboard.cjs`; `n_total` retained so band size stays visible.

## 3. Enforcement — removed, and here is the stronger reason

The sample-size objection was not the real problem. **"Declared blocks
enforced" is a category error.** robots.txt is an advisory instruction to
crawlers, not a server-side access control. A site that disallows GPTBot and
still serves a page is doing exactly what the protocol expects — it has not
"failed to enforce" anything, because there is nothing there to enforce. The
ratio measured a thing that does not exist.

- `rebuild.cjs` no longer computes `enforced_pct` (set to null, with the
  reasoning in the comment).
- `index.json`: `enforcement_headline` → `probe_panel_observations`, three
  counts and a note, no rate.
- `status.html`: the percentage is replaced by counts —
  *"…answered with a refusal N times and served the page M times"* — plus the
  advisory-protocol explanation and why no percentage follows.
- Removed *"consistent with independent findings of roughly 40%"* (unsourced).
- Added to `not_measured`: *"Whether any named crawler obeys any site's
  robots.txt directives."*

## 4. ccTLD labels — relabelled through the data layer, not just the copy

Fixed at the source so it cannot come back:

- `countryOf()` → `cctldOf()`, returning the **suffix** (".de", ".co.uk"),
  never a country name.
- `country_editions` → `cctld_editions`; `country_headline` →
  `cctld_headline`, with `cctld` keys and a caveat field.
- `world.html` payload rows now carry `cctld`, and its prose, table header,
  free-preview text and lock-panel all say ccTLD group.
- *"AI-crawler blocking is not global — it's national"* → *"varies sharply by
  domain suffix"*.
- `status.html`: *"ccTLD is a proxy for country"* → *"a domain suffix, not a
  country… generic suffixes carry no geography at all"*.

Side effect worth knowing: `.co.uk` and `.uk` are now separate groups rather
than both folded into "United Kingdom". `.co.uk` leads at 42.1% (n=261).

## 5. The homepage headline

*"Share of the scanned top 2,000"* → *"Share of the N domains with a readable
